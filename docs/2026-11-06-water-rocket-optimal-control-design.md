# 可変ノズル水ロケット高度最適化 — 数理モデル仕様 v1.0

作成日: 2026-11-06  
用途: MATLAB実装の設計基準。**本書は実装コードではない。**

## 1. 目的と合意事項

PETボトル級の単段水ロケットについて、**初期充填水量**と**噴射中のノズル有効開口面積の時間履歴**を同時に最適化し、発射位置からの**最大到達高度**を求める。

合意済み:

- 発射角 `theta0`、初期内部圧力 `p0` は利用者の指定値であり、最適化しない。
- タンク容積・乾燥質量・胴体最大直径を入力できる汎用的かつ簡潔なPETボトルモデルとする。
- 非定常の水噴射・圧縮空気噴射と、抗力を受ける2次元質点運動を採用する。
- 機体のピッチ・ヨー・ロール、揚力、風、流体のスロッシング、ボトル弾性、CFDは扱わない。
- 姿勢の代替仮定として、速度が十分にある間は推力方向を進行方向と一致させる。発射直後のみ指定発射角方向を用いる。
- ランチャー拘束モデルは必須にしない。ガイドや発射筒のモデルは将来のオプションとする。
- 可変ノズルの駆動方式は未定。機構に依存しない**有効開口面積**とその上下限・変更速度で表す。
- 当初言及された「エネルギー法（曲面・曲線）」は要件から外す。エネルギー収支は妥当性確認にのみ任意使用する。
- まずソルバ・モデルを設計する。実装指示書の承認前に実装しない。

## 2. モデルの守備範囲と限界

本モデルの出力は、指定された物理パラメータと**理想化した機体姿勢追従**の下での高度予測である。機体の静安定性・動安定性、ノズル駆動トルク、可変弁の耐圧、フラッタ、実機発射安全性を証明するものではない。

開口上下限・最大開口変更速度が指定されれば、最適な時間履歴は**それらの運動学的制約に対して実行可能**になる。ただし機構未定の段階では、圧力負荷下の駆動力・応答遅れ・開度依存の流量係数を確認できないため、実機実現性は暫定的なものと明記する。

圧力容器の許容圧力をシミュレーションが推定・保証しない。入力圧力は使用者が対象容器・継手の安全な許容値を別途確認する。

## 3. 物理パラメータと単位

計算内部はすべてSI単位。利用者向けのL・mm・度・ゲージ圧は入力層で変換する。

| 記号/推奨設定名 | 意味 | SI単位 | 要否 |
|---|---|---|---|
| `Vb` | タンク内容積 | m^3 | 必須 |
| `mDry` | 乾燥機体質量。ノズル駆動機構・電子機器を含む | kg | 必須 |
| `D` | 胴体の空力基準直径 | m | 必須 |
| `p0Abs` | 初期タンク絶対圧 | Pa | 必須。ゲージ圧から換算可 |
| `theta0` | 水平=0、鉛直上向き=pi/2 | rad | 必須 |
| `T0` | 初期タンク空気温度 | K | 既定値可 |
| `pAmb` | 外気絶対圧 | Pa | 既定値可 |
| `rhoAir` | 外気密度 | kg/m^3 | 既定値可 |
| `rhoW` | 水密度 | kg/m^3 | 既定値可 |
| `Cd` | 機体の抗力係数 | 無次元 | 既定値可・感度解析対象 |
| `gamma` | 空気の比熱比 | 無次元 | 既定値可 |
| `Rair` | 空気の比気体定数 | J/(kg K) | 物理定数 |
| `g` | 重力加速度 | m/s^2 | 物理定数 |
| `Amin`, `Amax` | 有効開口面積の上下限 | m^2 | 機構設計上の入力 |
| `ARateMax` | 有効開口面積の最大変化速度 | m^2/s | 機構設計上の入力 |
| `tControlEnd` | 制御点の末尾時刻 | s | 入力・初期推定値 |
| `nControlKnots` | 制御点数 | 個 | まず5〜6点 |

ゲージ圧 `pGauge = p0Abs - pAmb`。`p0Abs > pAmb`を要求する。`0 < Vw0 < Vb`、`0 <= Amin < Amax`、`ARateMax > 0`、`T0 > 0`、`mDry > 0`、`D > 0`を要求する。

既定物性値はコード上の設定ファイルへ集約し、モデル内部にマジックナンバーを埋め込まない。未知の実機値（特に`Amin`, `Amax`, `ARateMax`, `mDry`）は安全な実測値の代用品として勝手に決めない。サンプル設定と実機設定を明確に区別する。

## 4. 最適制御問題

水の初期充填率 `f = Vw0 / Vb` と、制御点における正規化開口率 `alpha_i` を最適化する。

\[
q=[f,\alpha_1,\ldots,\alpha_N]^\mathsf{T},\qquad
A(t)=A_{\min}+(A_{\max}-A_{\min})\alpha(t).
\]

`alpha(t)`は実時間上に等間隔配置した制御点 `(t_i, alpha_i)` の**区分線形補間**とし、`t ∈ [0,tControlEnd]`で定義する。終了後、推進が終わるまで**最終開口値を保持**する。先頭より前は先頭値を保持する。補間にスプラインのオーバーシュートを使わない。

制約は次のようにする。

\[
f_{\min}\le f\le f_{\max},\quad 0<f_{\min}<f_{\max}<1,
\]
\[
0\le\alpha_i\le1,
\qquad
|\alpha_{i+1}-\alpha_i|
\le \frac{R_A(t_{i+1}-t_i)}{A_{\max}-A_{\min}}.
\]

隣接点の変化率制約は`fmincon`へ**線形不等式**として渡せる。`tControlEnd`と制御点時刻は1回の最適化中は固定し、固定した開口スケジュールを飛行状態にフィードバックさせない。最適化後に生成する `A*(t)` は、そのまま時間基準の開ループ指令として再生可能である。

目的関数は、飛行が成立して最高点に到達した場合の `J(q) = -Hmax(q)`。飛行不能・数値積分失敗は、原因を診断情報に残した上で、その候補を採用しない。単純な `NaN` の返却は禁止する。

`A(t)`はノズル形状によらない**有効開口面積**であり、幾何学的口径そのものではない。表示用の等価円直径は `dEq(t)=sqrt(4*A(t)/pi)` とする。開度別の流量係数・圧力による流量変化は実測があれば後から差し替えられるようにする。

## 5. 状態と運動方程式

状態ベクトル:

\[
y=[x,z,v_x,v_z,V_w,m_a]^\mathsf{T}.
\]

`mDry` は不変、総質量 `m = mDry + rhoW*Vw + ma`。

\[
\dot x=v_x,\quad\dot z=v_z,
\]
\[
\dot{\boldsymbol v}=
\frac{F_T\boldsymbol e_T-\frac12\rho_{air} C_D S|\boldsymbol v|\boldsymbol v}{m}
-g\begin{bmatrix}0\\1\end{bmatrix},\quad S=\frac{\pi D^2}{4}.
\]

風はゼロとする。将来風を追加する場合は抗力に対気速度を用いる。推力方向:

\[
\boldsymbol e_T=\begin{cases}
[\cos\theta_0,\sin\theta_0]^\mathsf{T}& |\boldsymbol v|<v_\epsilon,\\
\boldsymbol v/|\boldsymbol v|& |\boldsymbol v|\ge v_\epsilon.
\end{cases}
\]

`vEpsilon`はゼロ割り回避のための小さな数値パラメータ。姿勢追従の物理的時定数を表すものではない。閾値前後の解への感度を検証する。初期 `x=z=vx=vz=0`。

## 6. 水噴射フェーズ（Phase W）

初期空気体積 `Va0=Vb-Vw0`、初期空気質量 `ma0=p0Abs*Va0/(Rair*T0)`。水噴射中は `ma=ma0` 一定。断熱・理想気体近似を使う:

\[
V_a=V_b-V_w,\quad
p=p_0\left(\frac{V_{a0}}{V_a}\right)^\gamma,\quad
T=T_0\left(\frac{V_{a0}}{V_a}\right)^{\gamma-1}.
\]

`deltaP = max(p-pAmb,0)`とし、簡易の有効開口モデル:

\[
u_w=\sqrt{2\Delta p/\rho_w},\qquad
\dot V_w=-A(t)u_w,\qquad
F_T=\rho_w A(t)u_w^2=2A(t)\Delta p.
\]

有効面積が流量損失を吸収する一次近似であり、速度損失や収縮損失の差異は含まない。精度が足りなければ、設定可能な速度係数／流量係数へ拡張する。水の圧縮性、水柱静水圧、加速度による水面圧力補正、タンク内液面運動を省略する。

Phase W のイベント:

1. `Vw == 0`：`p > pAmb`ならPhase Aへ、それ以外はPhase Cへ。
2. `p == pAmb`：未排出の水は質量として残し、Phase Cへ。
3. 上昇中の鉛直速度が正から負へ変化した：最高点として終了。
4. 地面へ落下／上昇不能：候補を飛行不能として終了。

`Vw`の負値はイベント時刻を精密に特定して防ぐ。フェーズ切替時に位置・速度・残存質量を不連続に変えない。

## 7. 空気噴射フェーズ（Phase A）

水がゼロで、内部圧が外気圧を上回る場合のみ開始する。開始状態 `p1,T1,ma1` を保存し、剛体タンクからの断熱ブローダウンを採用:

\[
p=p_1(m_a/m_{a1})^\gamma,\qquad
T=T_1(m_a/m_{a1})^{\gamma-1}.
\]

`r=pAmb/p`、臨界圧力比 `rCrit=(2/(gamma+1))^(gamma/(gamma-1))`。流出質量流量の正の値 `mDotOut` は、単純な等エントロピーノズル近似で:

\[
\dot m_{out}=A(t)p\sqrt{\frac{\gamma}{R_{air}T}}
\begin{cases}
\left(\frac{2}{\gamma+1}\right)^{\frac{\gamma+1}{2(\gamma-1)}} & r\le r_{crit},\\[3pt]
\sqrt{\frac{2}{\gamma-1}\left(r^{2/\gamma}-r^{(\gamma+1)/\gamma}\right)}&r_{crit}<r<1,\\
0&r\ge1.
\end{cases}
\]

`maDot=-mDotOut`。非チョーク時は `pe=pAmb`、`ue=sqrt(2*gamma*Rair*T/(gamma-1)*(1-r^((gamma-1)/gamma)))`。チョーク時は `pe=p*(2/(gamma+1))^(gamma/(gamma-1))`、`Te=T*2/(gamma+1)`、`ue=sqrt(gamma*Rair*Te)`。

\[
F_T=\dot m_{out}u_e+(p_e-p_{amb})A(t).
\]

有効開口をスロート面積として流用する近似であり、チョーク時の圧力推力の精密予測は機構依存性が残る。この範囲でモデルの簡潔さを優先する。`r`の境界で質量流量・推力が不自然に跳ばないことをテストする。

Phase A は `p <= pAmb` でPhase Cへ。最高点が先に来ればそこで終了。

## 8. 慣性飛行フェーズ（Phase C）

`F_T=0`、`Vw`と`ma`は定数。位置・速度の運動方程式のみ積分する。

最高点イベント `vz=0` の**正→負**の横断時刻を `ode45` のEventsで求め、そのときの高度を `Hmax` とする。初期時刻の `vz=0` を誤検出しないよう、上昇開始後に最高点イベントを有効化する。最高点より先の落下・着地は目的関数に不要なので積分しない。

## 9. 数値積分と制御時間

- 既定ソルバは `ode45`、`odeset('Events',...)` を用いてフェーズを分離する。
- 状態ごとに適切な `AbsTol` を設定し、`RelTol`とともに精度収束を確認する。必要に応じて `MaxStep` を最小制御点間隔より十分小さくする。
- `tControlEnd` は**実時間**の固定ノット末尾。予備計算（一定開口の数ケース）から推進時間の桁を推定し、その範囲を覆う値を利用者が調整できるようにする。
- 制御末尾より長く推進が続く場合、最後の開口を保持して飛行を継続する。ただしこの状況を診断表示し、最適化後に `tControlEnd` の拡張感度を確認する。
- `maxFlightTime` は無限ループ防止の上限。これに達して最高点が未検出なら成功扱いしない。
- 微小な負圧差、負の残存質量、`p<pAmb`を数値丸めで作らない。
- 必ず「初期水量ゼロ付近」「ほぼ満水」「最小開口」「閉鎖可能な開口」「初圧が外気圧以下」「飛行不能」を明示的に処理する。

## 10. 最適化アルゴリズム

**直接単一シューティング法**。決定変数は `q=[f,alpha_1,...,alpha_N]` のみで、各評価ごとにODEを最初から最高点まで積分する。

1. 予備探索: 水量を複数値、ノズルを一定開口とした基準ケースを評価する。
2. 最良の一定開口ケースを、全 `alpha_i` が同じ実行可能な初期値として採用する。
3. `fmincon`（`sqp`）で制約付き局所最適化。複数初期値を試し、最も高い実行可能解を採用する。
4. Global Optimization Toolbox利用可能時は `ga` などで追加の大域探索を実施できるようにする。必須依存にはしない。
5. ODEの許容誤差、ノット数、制御末尾時刻を変えた再解析で最適値の頑健性を確認する。

MATLABの標準機能 `ode45` は使用可能。`fmincon` には Optimization Toolbox が必要。Global Optimization Toolboxは**任意**。Optimization Toolboxがない環境では、制約を厳密に守れる代替パラメータ化を実装するまで最適化完了を宣言しない（`fminsearch`＋単純な罰則だけで制約保証済みと称さない）。

一定開口の候補が可変開口最適化の実行可能集合に含まれるので、最終採用解は最良一定開口基準ケースより悪くならないように、**基準ケース自体を候補として保持**する。

## 11. 入出力と表示

入力: `cfg` 構造体による機体、環境、ノズル、制御、ソルバ設定。画面UIは必須ではない。

出力: `result` 構造体に次を記録する。

- 最適初期水量、充填率、初期圧力（ゲージ／絶対）、発射角度。
- 最適ノズル有効面積・等価開口径の制御点、完全な時間履歴。
- 最高点高度と到達時刻、機体速度、位置、タンク圧力、残水量、残空気量、推力、総質量。
- 水噴射終了・空気噴射終了のイベント時刻と終了理由。
- 一定開口での最良基準高度、改善量、改善率（基準高度が正のときのみ）。
- 制約の最大違反量、最適化収束状態、ODE失敗回数、ノット数と制御時間。
- 実機での未検証事項（開度依存損失、実装可能な開口速度、駆動力など）の注意書き。

最低限の図: `A(t)`・`dEq(t)`、`z(t)`、`p(t)`、`Vw(t)`、`F(t)`、`vx(t)`・`vz(t)`、2D軌道。任意に水量対最高点の感度曲線、エネルギー収支・一定開口との比較を追加する。

## 12. 検証・受入基準

1. `A(t)`が範囲と変更速度の制約を数値誤差内で必ず満たす。
2. 水噴射中は `Vw` が非増加、気体が膨張する限り `p` が非増加。
3. 空気噴射中は `ma` と `p` が非増加。チョーク境界で流量・推力が有限かつ連続。
4. フェーズ切替前後で位置・速度・残質量が連続し、状態が負にならない。
5. 空気抵抗ゼロで垂直発射なら、理想対称条件下で水平速度・水平変位がほぼゼロ。
6. 最高点は上昇中の `vz>0` から下向き横断したイベントで求め、初期 `vz=0` を最高点と誤認しない。
7. 上昇不能・圧力不足・ノズル閉鎖等は成功と混同しない診断を返す。
8. 最適解の最高点高度が、別途保存した最良の一定開口候補より小さくならない。
9. `RelTol`／`AbsTol`を厳しくし、制御点を増やしたときの高度・スケジュール変化を報告する。
10. コードは最小限の MATLAB標準機能で動作し、追加Toolbox不足は明示的に説明する。
